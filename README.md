Task18- Missing Values in Pandas

## Project Overview

This project demonstrates how to identify, analyze, and handle missing values in a dataset using Python and Pandas.

The **Titanic dataset** is used for this project. The dataset contains information about passengers who
 travelled on the Titanic, including their age, gender, passenger class, fare, cabin, and survival status.

## Objective

The main objectives of this project are:

- Identify missing values in the dataset
- Calculate the number and percentage of missing values
- Use Pandas functions such as `isna()`, `isnull()`, and `notna()`
- Handle missing values using different techniques
- Compare the dataset before and after cleaning
- Create and save a cleaned dataset


## Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

Conclusion

This project demonstrated how Pandas can be used to identify and handle missing values in a real-world dataset.

The Titanic dataset was analyzed to find missing values, calculate their percentages, and apply appropriate
 techniques such as median imputation, mode imputation, and column removal.
